# Yashfa Amjad | Personal Portfolio

Welcome to my personal portfolio! I'm **Yashfa Amjad**, a Software Engineering student at Lahore Garrison University and an aspiring Web Developer.

This portfolio showcases my skills, projects, education, and internship experience. It is designed to provide a simple and professional overview of my journey in software engineering and web development.


## ✨ Features

- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Light & Dark Mode:** Switch between two visual themes.
- **About Section:** Introduction and background.
- **Projects Showcase:** Displays projects with GitHub repositories and live demos.
- **Skills Section:** Highlights programming languages, tools, and development skills.
- **Education & Experience:** Displays academic background and internship experience.
- **Contact Form:** Allows visitors to send messages using EmailJS.
- **Interactive Navigation:** Smooth scrolling, active navigation links, and a mobile menu.
- **Accessibility:** Includes keyboard-friendly navigation and reduced-motion support.

## 🚀 Run Locally

You can view the portfolio on your computer by following these steps:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional installation or build process is required.

## 📧 Contact Form Setup

The contact form uses **EmailJS** to send messages directly to my inbox without requiring a custom backend.

To configure it for your own portfolio:

1. Create an account on [EmailJS](https://www.emailjs.com/).
2. Set up an email service.
3. Create an email template.
4. Add your EmailJS configuration to the JavaScript section of the HTML file.
